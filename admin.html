관리자 연결

이 페이지는 GitHub 저장소에 직접 저장합니다. 한 번만 토큰을 넣어두면 이 브라우저에 기억됩니다.

  1. GitHub 로그인 후 새 Fine-grained 토큰 만들기를 엽니다.
  2. Token name은 아무거나, Expiration은 길게(예: 1년).
  3. Repository access에서 Only select repositories → houseofjoy 선택.
  4. Permissions → Repository permissions → Contents를 Read and write로.
  5. Generate token을 누르고, 나온 토큰(github_pat_…)을 아래에 붙여넣습니다.

항목

    장면

      새 항목

      새 장면

      장면에 들어갈 항목은 각 항목 편집 화면의 "장면에 넣기"에서 고릅니다.

      왼쪽에서 항목을 고르거나 + 새 항목을 누르세요.

      저장하면 GitHub에 바로 기록되고, 사이트에는 보통 1~2분 안에 반영됩니다.
